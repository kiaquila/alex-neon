## Images

`website/assets/community-mark.jpg` is the avatar of the client's Telegram
community. It was added on the client's instruction, not carried over from the
original landing, and is hosted locally so the page makes no external request.
`website/assets/ks-design-signature.png` is the KS Design developer signature,
added to the footer on 2026-08-14. Both decisions are recorded in
`CONTENT-AUDIT.md`.

`website/assets/og.png` is generated by this repository
(`npm --prefix website run og`) rather than copied from the source hosting, and
`website/assets/favicon.svg` is an original monogram drawn for this redesign.
